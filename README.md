# Мир колодцев · Вики

Энциклопедия мира колодцев из романа Романа Суржикова «Следы на воде» на русском языке.
Устроена так же, как [Полари Вики](https://polari.wwworm.com), и собрана на том же движке.

## Что здесь есть

- **Статьи** о романе, персонажах, странах, местах, событиях и понятиях мира.
- **Карта и шкала времени**: авторская карта с метками и путь героев по главам.
- **Схема связей** персонажей.
- **Хронология**, **глоссарий**, **цитаты**.
- **Испытания**: тесты на знание романа трёх уровней сложности.

Всё написано по тексту романа, авторской карте и двум стримам с автором.

## Защита от спойлеров

Поле «Прочитано до» в шапке сайта скрывает главы, которые вы ещё не прочитали.
Разделы статей с пометкой «(гл. N)» в заголовке сворачиваются, общие разделы размываются,
а поздние события пропадают с карты, шкалы времени и схемы связей.

## Как устроен репозиторий

```
content/<тип>/<slug>.md   статьи (Markdown с шапкой; ссылки [[slug]] или [[slug|текст]]; поле chapters: — главы, где герой появляется)
data/                     указатель глав, страны, связи персонажей (столбец ch — глава), точки на карте, вопросы испытаний (quiz.json)
images.tsv                какие иллюстрации к каким статьям относятся
build.py                  собирает данные сайта в web/public/data/
web/scripts/pages.mjs     после сборки сайта пишет страницу на каждую статью, sitemap.xml и robots.txt
web/                      сайт на Angular
```

## Как запустить у себя

    python3 build.py              # пересобрать данные после правок в content/ или data/
    cd web && npm ci && npx ng serve

Сайт откроется на http://localhost:4200.
